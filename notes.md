## Accessibility
.focus() - You can manually add focus to different objects on a site using the js focus method. This is helpful for when you want screen readers' focus to jump to important things like a close button.
[ARIA live regions](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Guides/Live_regions) - When JS is used to update part of a page without reloading, the updated elements will not be immediately obvious to screenreader users. ARIA live regions help fill this gap by announcing changes through assistive technology.
<span aria-hidden="true"><span> - This marks elements as decorative for screenreaders.
